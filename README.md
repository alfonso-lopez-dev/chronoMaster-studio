# ChronoMaster Studio ⏱️

**ChronoMaster Studio** es una aplicación web moderna y elegante para la gestión inteligente del tiempo. Diseñada con una interfaz futurista y funcional, permite a los usuarios gestionar múltiples temporizadores y cronómetros simultáneamente en un entorno visual tipo dashboard.

![ChronoMaster Banner](https://img.shields.io/badge/ChronoMaster-Studio-indigo?style=for-the-badge&logo=clock)

## ✨ Características Principales

*   **Dashboard Multitarea:** Gestiona hasta **5 dispositivos de tiempo** simultáneos (Temporizadores y Cronómetros).
*   **Diseño Adaptativo:** Interfaz construida con **Tailwind CSS** que se adapta a diferentes tamaños de pantalla, con un diseño de rejilla inteligente.
*   **Cronómetro Avanzado:**
    *   Visualización destacada de doble altura.
    *   Registro de vueltas (Laps) con scroll infinito.
    *   Cálculo de tiempos parciales y totales.
*   **Temporizadores Personalizables:**
    *   Configuración de horas, minutos y segundos.
    *   Presets rápidos (1m, 5m, 10m, 20m, etc.).
    *   **Sonidos de Alarma Seleccionables:** Elige entre varios tonos (Beep Clásico, Digital, Zen, Arcade, Sirena, Industrial).
*   **Interfaz Interactiva:**
    *   **Drag & Drop:** Reordena tus temporizadores arrastrándolos y soltándolos.
    *   Barra de progreso visual con cambio de color según urgencia.
    *   Animaciones suaves y efectos visuales de "alarma activa".
*   **Persistencia y Seguridad:**
    *   Modales de confirmación para evitar reinicios accidentales.
    *   Validación de límites de creación.

## 🛠️ Tecnologías Utilizadas

*   **HTML5:** Estructura semántica.
*   **CSS3 / Tailwind CSS:** Estilos modernos, responsivos y animaciones.
*   **JavaScript (ES6+):** Lógica de estado, manejo del tiempo (Web Audio API para sonidos) y manipulación del DOM.
*   **Lucide Icons:** Iconografía limpia y ligera.

## 🚀 Cómo Usar

1.  Clona este repositorio:
    ```bash
    git clone https://github.com/alfonso-lopez-dev/chronoMaster-studio.git
    ```
2.  Navega a la carpeta del proyecto:
    ```bash
    cd chronoMaster-studio
    ```
3.  Abre el archivo `index.html` en tu navegador web favorito. ¡No requiere instalación de dependencias ni servidor backend!
